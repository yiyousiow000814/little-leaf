# Build sale refunds (0.1.10 follow-up to PR60)

This follow-up extends the memory-only Decorate purchase receipts to player-built half/full walls and purchased doors/windows. Before Done, removal refunds their full current-session purchase charge: half wall35, full wall55, door40, window30. After Done or successful reload, existing resale remains17/27/20/15 respectively. Existing objects are never promoted by Decorate entry; the free starter door stays0. Opening paid_cost and the save schema remain unchanged.

Wall and opening receipts use separate stable-ID namespaces. Moving, changing free wallpaper, preview cancellation and autosaving preserve eligibility; failed purchase/removal and duplicate removal transfer no money. Host walls cannot be removed until their attached opening is safely removed or moved. An opening removal blocked by an active stove workface retains its receipt until safely unblocked. Successful no-refund removal still consumes eligibility. Done, reload and new-profile reset clear both furnishing and Build receipts.

Player-wall replacement quotes and net credits are unchanged: the existing wall returns its existing half-price replacement credit, and the replacement purchase records the new product gross cost as its single active receipt. The old purchase receipt is retired by overwrite under the stable wall ID. Example: half35 replaced by full55 uses17 replacement credit, charges38 net, then sells for55 before Done; the old half wall has lost18 exactly once. Old wall replacement likewise retains the old half credit and fully refunds only the newly purchased replacement product. Direct wall height changes retain their existing exact difference charge/refund and adjust an already eligible wall receipt by that same difference, preventing a55->35->55 cycle from creating credit. Free painting preserves the current product receipt. Shell replacements and floor-tile replacement credits are untouched and do not gain standalone resale actions; land has no resale action. Stove upgrade costs remain excluded from furnishing refund receipts.

The actual compact Sell labels and wall-removal preview read the authoritative model refund. Furnishings PR60 remains an independently reviewable checkpoint; its excluded-category table describes that checkpoint, and this follow-up supplies wall/opening resale coverage.

Tests use only disposable generated saveguard profiles and --headless engine processes. They cover old/new objects, opening movement, blocked host/removal then unblock, autosave/reload, Done/reentry, non-refunding removal, ID reset, insufficient funds, height cycles, unchanged replacement credits, failed replacements and actual Sell label values. The strengthened furnishing suite covers Done with a failed save; nonempty receipt reset followed by exact ID reuse; odd price45; separate stove220+upgrade180 charges; free bin0 before Done and existing32 after; failed eligible new-item essential/in-use sales then unblock; malformed load; insufficient funds; and a stale planner after selling an eligible object.
