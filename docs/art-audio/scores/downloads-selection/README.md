`_2nd` belong to **Premium**, preserving the user's filenames and spelling.
Premium is currently free; its tooltip explains that charging is planned for
the future. No payment, entitlement or inaccessible-track rule is introduced.
One MP3/WAV pair represents one selectable version, not two songs. Masters,
stems, seam auditions and repeated-cycle previews are production material.

Study A/B selections remain separate and must be retained. The unmarked Shop
track retains the earlier Decorate-only context rule. Sunshine Skip176BPM is
distinct from the marked150BPM R6 version. The package's creation-time status
