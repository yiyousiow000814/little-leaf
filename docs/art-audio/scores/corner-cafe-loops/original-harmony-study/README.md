# Corner Cafe：和声减法 A/B 试听

这不是 Restaurant City 还原，也不是所给 YouTube 链接的转录。尚未取得参考视频的音频，未下载、采样或听写这八首参考。

## 听什么

- A_V2_control.mp3：我们原有 Corner Cafe V2 的前八小节重新渲染，加两拍共同收尾；并非原 MP3 的逐样本剪辑。
- B_reduced_harmony.mp3：相同主题轮廓、速度、节拍、主奏音源，减少和声张力和装饰声部的候选。
- AB_comparison.mp3：A 约20.01秒，静音1秒，B约20.01秒。

两版均为112 BPM；使用同一 TimGM6mb SoundFont、同一套滤波/混响处理及来自控制版的每轨增益标定，最终统一到约 -18 LUFS。母线增益稍有差别，是为了避免只因更大声而误判。尚未做用户听感验收。

## 改动

1. 保留 E-G-A 的主题动机及前八小节的主要节奏；两处伴随 A 和弦的 C#5 改为 C5，配合由 A7/A7(b9) 改为 Am7。
2. C6/9、Dm9、G13 等较密集和弦在 B 中减为 C6、Dm7、G7；这是风格取舍，不代表九和弦或十三和弦错误。
3. 低音不再按“下一和弦根音减一个半音”等公式产生连接；八小节逐一指定连接音。
4. 去掉 flute、vibraphone、连续 shaker 和加花打击声部；保留电钢琴、吉他、低音及克制的鼓点。
5. 让吉他减少重复打击并准确落在和声变化点，保留稳定的节奏骨架。

这是一个组合的减法实验，不是单变量测试。若 B 更舒服，只能说明这一组改动方向值得保留，不能单独认定某一个因素就是此前听感不佳的原因。简单不自动等于更好，最终听感由用户判断。

## 可编辑资料

两份 MIDI 是带发音长短、力度与少量时间偏移的演奏数据。两份 MusicXML 是主旋律及和弦的 lead sheet，不是全编制总谱。JSON 是精确演奏事件。伴奏和打击乐的权威细节见 JSON 与脚本。

重建示例（需要与 V2 相同的 Python/FluidSynth/FFmpeg 依赖，无网络调用）：

```
python source/make_study.py --source source/original_create_corner_cafe.py --out ./rebuilt --soundfont /path/to/TimGM6mb.sf2
```

脚本使用当前环境免费音源作试听。本包不含 SoundFont 或字体文件；保留原音源许可记录，不作商业发行授权保证。没有修改 GitHub、Dots 任务、游戏BGM或线上版本。
