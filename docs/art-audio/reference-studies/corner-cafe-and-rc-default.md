## 已有参考分析如何使用

原 MP3 的 SHA-256 对得上此前分析源。旧分析给出约 120 BPM 和约 32.09 秒的重复周期；
这些是分析结果，不是原作工程设置。音色判断只到电钢琴/拨弦伴奏/低音/轻打击的家族和角色，
不宣称已知原始插件、具体乐器或完整乐谱。重测与旧证据放在交付包 evidence 中；
旧的听感文字仍按历史来源理解，本次没有据此虚构一次新的独立人耳审核。

参考的主要启发是稳定节奏、反复中有呼吸、柔和音头及声部互补。没有规则规定：
简单和弦一定好，复杂和弦一定差，低音不能在第 1/3 拍，或者每小节都必须变化。

## 给 Agent 的执行规则

先核对实际文件，再进行试听和改良。用户明确喜欢的是具体录音，不是曲名或生成脚本。
保留好听的主体，只对可说明的问题做改动。新候选没有用户意见就保持 Pending；
导出成功、乐谱正确和技术检查不等于更顺耳，不写“已达到人类专业水平”等无证据结论。
