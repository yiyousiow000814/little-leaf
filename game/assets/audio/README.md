# Little Leaf Cafe music provenance

MUSIC PROVENANCE AND SUPPLIER LICENCE

The three included original Little Leaf Cafe release 1.1 MP3 recordings are
preserved byte-for-byte. Their hashes match the September 30 production record.
That record identifies locally authored notes rendered with FluidSynth 2.4.4
and GeneralUser GS 2.0.3 as the sole sampled-instrument bank.

GeneralUser GS licence version 2.0 supports private and commercial music
creation and recordings, including these soundtracks in a free public or
commercial game. No express fee or attribution requirement for rendered music
was found in that licence.

The supplier discloses incomplete historical provenance for some samples.
This is documented supplier permission, not an independent non-infringement
guarantee. The original composition files and SoundFont have not been recovered;
the historical SoundFont checksum remains unverified.

See MUSIC_PROVENANCE_ADDENDUM.json for exact track hashes and evidence and
GeneralUser-GS-LICENSE.txt for the full licence.
https://github.com/mrbumpy409/GeneralUser-GS/blob/main/documentation/LICENSE.txt

This notice updates only the music-provenance assessment. It does not establish
whole-game release readiness, alter private/public settings or authorize a
publication action.
